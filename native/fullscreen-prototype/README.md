# 전체화면 안내 보조 프로그램

이 실험적 기능은 시험모드 중 웨일의 전체화면 종료 안내 창을 숨깁니다. 비슷한 다른 웨일 창도 숨겨질 수 있고 브라우저 업데이트에 따라 작동하지 않을 수 있습니다. 시험 감독 프로그램과의 호환성은 확인되지 않았습니다. **실제 시험 전에 학교의 규정과 동작을 확인하세요.** 보조 프로그램이 연결되지 않으면 자동 전체화면 진입을 기다립니다.

안내를 숨기는 것만으로 시험 기록이나 감점 여부가 보장되지는 않습니다. Canvas의 일부 퀴즈 로그는 다른 탭이나 프로그램으로 이동한 상태를 표시할 수 있습니다. 안내 창 자체가 특정 시험에서 어떻게 기록되는지는 확인되지 않았습니다. [Canvas 퀴즈 로그 안내](https://community.instructure.com/en/kb/articles/661037-how-do-i-view-a-quiz-log-for-a-student)를 참고하세요. [학교의 2022년 온라인 시험 안내](https://amse.skku.edu/AMSE/notice.do?article.offset=460&articleLimit=10&articleNo=133030&mode=view)는 크롬 사용과 과목별 모의시험 점검을 권장합니다. 이 보조 프로그램은 웨일 전용이므로, 해당 과목의 최신 브라우저·시험 지침을 먼저 확인하세요.

설치는 Windows x64의 웨일을 대상으로 합니다. 보조 프로그램은 이 확장에 포함된 소스에서 빌드하며, 빌드에 MinGW 대상 `clang-20.exe`가 필요합니다. 예를 들어 [Windhawk](https://windhawk.net/)에 포함된 컴파일러를 사용할 수 있습니다. 프로그램을 설치해도 해당 기능을 켜기 전에는 안내 창을 숨기지 않습니다.

이 기능은 처음에 꺼져 있습니다. 설정의 **“시험 중 전체화면 안내를 숨겨요”**는 기능 설명이며, 보조 프로그램의 설치 여부를 확인한 결과는 아닙니다. **켜기**를 선택하면 권한과 보조 프로그램 연결을 확인합니다.

1. 웨일의 확장 관리 화면에서 아캠 플러스의 **확장 ID**를 확인합니다.
2. PowerShell을 열고 아캠 플러스 확장 폴더로 이동합니다.
3. 아래 명령에서 두 값을 실제 확장 ID와 `clang-20.exe`의 전체 경로로 바꾸어 실행합니다. Windhawk를 사용한다면 컴파일러는 Windhawk 폴더의 `Compiler\bin`에 있습니다.

```powershell
.\native\fullscreen-prototype\install.ps1 -ExtensionId '<확장 ID>' -Compiler '<clang-20.exe 전체 경로>'
```

4. 아캠 플러스 설정에서 **전체화면 안내 숨기기**를 켜고 요청하는 권한을 허용합니다. 다른 웨일 프로필에서도 쓰려면 그 프로필의 설정에서 따로 켜야 합니다.
5. 실제 시험 전에 일반 아이캠퍼스 화면에서 시험모드를 수동으로 시작해 전체화면 안내와 Windows 키 동작을 확인하고, 시험모드를 끝냅니다. 감독용 확장이 필요하면 **시험 중에도 켤 확장**에 먼저 추가하세요.

연결에 실패하면 자동 전체화면으로 들어가지 않습니다. 보조 프로그램을 다시 설치하고 확장을 새로고침한 뒤 설정을 확인하세요. 기능을 끄면 시험모드에서 보조 프로그램을 연결하지 않습니다. 등록을 지우려면 기능을 끈 뒤 확장 폴더에서 다음 명령을 실행하세요.

```powershell
.\native\fullscreen-prototype\install.ps1 -Uninstall
```

보조 프로그램의 나머지 파일은 웨일을 종료한 후 `%LOCALAPPDATA%\WhaleExtentions\IcampusFullscreenHost`에서 지울 수 있습니다. 크롬에서는 기존 시험모드를 사용할 수 있지만, 현재 보조 프로그램은 웨일 프로세스와 웨일의 등록 위치를 사용하므로 다른 크로미움 브라우저에 그대로 연결되지 않습니다. 비슷한 방식을 다른 브라우저에 적용할 가능성은 있지만 지원 여부는 확인되지 않았습니다.

## 동작 원리

`notice-hook.cpp`는 MinHook으로 웨일 프로세스의 `ShowWindow` 표시 요청을 가로채 창 종류와 스타일이 일치하면 표시를 막는다. 종료 안내 외에 조건이 같은 다른 웨일 창도 숨겨질 수 있다. Windows나 웨일 업데이트 후 동작이 달라질 수 있다.

확장은 시험모드가 활성인 동안에만 `host.cmd`와 `host.ps1`에 연결한다. 호스트는 자신을 실행한 웨일 프로세스를 찾아 `operate.ps1`로 후킹을 시작하고 종료한다. 호스트가 비정상 종료되면 대상 프로세스의 감시 스레드가 후킹 해제를 시도한다. 중지 뒤에도 콜백에 진입한 스레드가 참조할 수 있어 DLL과 연결 코드는 웨일 프로세스가 종료될 때까지 메모리에 남는다.

`install.ps1`은 확장 ID와 MinGW clang 경로를 받아 사용자 로컬 폴더에 빌드하고 현재 사용자에 대해서만 웨일의 보조 프로그램을 등록한다. 별도 `-Uninstall` 실행으로 등록을 제거할 수 있다. 설정에서 기능을 끄고 웨일을 종료한 뒤 남은 파일을 지울 수 있다.

`operate.ps1`의 PID 직접 지정은 개발 실험용이며 사용자용 설치 절차가 아니다. MinHook 1.3.4의 저작권과 라이선스는 `minhook/LICENSE.txt`에 있다. GitHub의 안내 차단 모드와 동작 원리를 비교해 별도로 작성했다.
