# 전체화면 안내 보조 프로그램

이 실험적 기능은 시험모드 중 브라우저의 전체화면 종료 안내 창을 숨깁니다. 비슷한 다른 창도 숨겨질 수 있고 브라우저 업데이트에 따라 작동하지 않을 수 있습니다. 시험 감독 프로그램과의 호환성은 확인되지 않았습니다. **실제 시험 전에 학교의 규정과 동작을 확인하세요.** 보조 프로그램이 연결되지 않으면 자동 전체화면 진입을 기다립니다.

안내를 숨기는 것만으로 시험 기록이나 감점 여부가 보장되지는 않습니다. Canvas의 일부 퀴즈 로그는 다른 탭이나 프로그램으로 이동한 상태를 표시할 수 있습니다. 안내 창 자체가 특정 시험에서 어떻게 기록되는지는 확인되지 않았습니다. [Canvas 퀴즈 로그 안내](https://community.instructure.com/en/kb/articles/661037-how-do-i-view-a-quiz-log-for-a-student)를 참고하세요. 해당 과목의 최신 브라우저·시험 지침을 먼저 확인하세요.

설치 프로그램은 Windows x64와 Chrome, Whale, Edge, Brave, Vivaldi, Chromium을 대상으로 합니다. 프로그램을 설치해도 해당 기능을 켜기 전에는 안내 창을 숨기지 않습니다. 브라우저별 연결 동작은 환경에 따라 다를 수 있습니다.

이 기능은 처음에 꺼져 있습니다. 설정의 **“시험 중 전체화면 안내를 숨겨요”**는 기능 설명이며, 보조 프로그램의 설치 여부를 확인한 결과는 아닙니다. **켜기**를 선택하면 권한과 보조 프로그램 연결을 확인합니다.

1. 아캠 플러스 설정의 **Windows 보조 설정 > 파일 받기**를 누르고 받은 파일을 엽니다.
2. 사용할 브라우저를 고르고 **전체화면 보조 설치**를 누릅니다. 받은 파일 이름에 담긴 확장 ID에 연결하므로 이름을 바꾸지 마세요.
3. 확장 설정에서 **전체화면 안내 숨기기**를 켜고 요청하는 권한을 허용합니다. 다른 프로필에서도 쓰려면 그 프로필의 설정에서 따로 켜야 합니다.
4. 실제 시험 전에 학교의 시험 지침과 동작을 확인하세요. 감독용 확장이 필요하면 **시험 중에도 켤 확장**에 먼저 추가하세요.

연결에 실패하면 자동 전체화면으로 들어가지 않습니다. 보조 프로그램을 다시 설치하고 확장을 새로고침한 뒤 설정을 확인하세요. 연결을 지우려면 기능을 끄고 받은 프로그램을 다시 열어 같은 브라우저의 **전체화면 보조 연결 해제**를 누르세요. 남은 파일은 브라우저를 종료한 후 `%LOCALAPPDATA%\WhaleExtentions\IcampusFullscreenHost`에서 지울 수 있습니다.

## 동작 원리

`notice-hook.cpp`는 MinHook으로 브라우저 프로세스의 `ShowWindow` 표시 요청을 가로채 창 종류와 스타일이 일치하면 표시를 막는다. 종료 안내 외에 조건이 같은 다른 창도 숨겨질 수 있다. Windows나 브라우저 업데이트 후 동작이 달라질 수 있다.

확장은 시험모드가 활성인 동안에만 `host.cmd`와 `host.ps1`에 연결한다. 호스트는 자신을 실행한 브라우저 프로세스를 찾아 `operate.ps1`로 후킹을 시작하고 종료한다. 호스트가 비정상 종료되면 대상 프로세스의 감시 스레드가 후킹 해제를 시도한다. DLL과 연결 코드는 브라우저 프로세스가 종료될 때까지 메모리에 남는다.

`HelperInstaller.cs`는 선택한 브라우저의 현재 사용자 등록만 변경한다. `build-installer.ps1`은 MinGW clang과 Windows의 .NET 컴파일러로 포함된 실행 파일을 만든다. 기존 `install.ps1`은 압축 해제판 등 다른 확장 ID의 개발용 수동 설치에 쓴다.

`operate.ps1`의 PID 직접 지정은 개발 실험용이며 사용자용 설치 절차가 아니다. MinHook 1.3.4의 저작권과 라이선스는 `minhook/LICENSE.txt`에 있다. GitHub의 안내 차단 모드와 동작 원리를 비교해 별도로 작성했다.
